# phase-math — обратимая математика для парадигмы PHASE

[English](README.md) | Русский

Математика **внутри фазы** = биекции на Z/2^64 с **аналитически вычисляемыми
инверсиями**: `MulOdd(m)` (умножение на нечётную константу — биекция; обратная
операция — `MulOdd(m⁻¹)` через модулярную инверсию методом Ньютона), `Add`,
`Xor`, `RotL`, обратимые ARX-раунды. Любая композиция — биекция, значит любая
формула точно отменяется: `F⁻¹(F(x)) == x` — это свойство, а не обещание.

Float-математика необратима и живёт **на границе фазы**. Этот крейт —
числовой слой для этой границы: фиксированная точка и интервальная
арифметика с документированными, проверенными тестами бюджетами погрешности,
чтобы VM могла решать, какие вычисления обратимы точно и что должен отменять
rollback.

## Быстрый старт

phase-math пока не опубликован на crates.io — подключайте из git:

```bash
cargo add --git https://github.com/kostyk348/phase-math phase-math
```

или в `Cargo.toml`:

```toml
[dependencies]
phase-math = { git = "https://github.com/kostyk348/phase-math" }
```

Минимальный пример:

```rust
use phase_math::{Compose, Interval, Op, Q16};

fn main() {
    // 1. Биекции на Z/2^64: любая композиция обращается аналитически.
    let mut enc = Compose::new();
    enc.push(Op::MulOdd(0x9E37_79B9_7F4A_7C15)); // нечётный множитель
    enc.push(Op::Add(0xD1B5_4A32_D192_ED03));
    let dec = enc.inverse();
    assert_eq!(dec.apply(enc.apply(42)), 42);

    // 2. Фиксированная точка (здесь Q16.16): точно, когда значение
    //    представимо; None (или документированная граница ошибки) иначе.
    let x = Q16::from_i32(3).unwrap(); // 3.0
    let y = Q16::from_i32(7).unwrap();
    assert_eq!(x.checked_mul(y), Q16::from_i32(21)); // точно: 21 * 2^16 делится
    assert_eq!(x.checked_mul(Q16::MAX), None); // вне домена -> откат фазы

    // 3. Насыщающие варианты сообщают о клампинге флагом.
    let s = Q16::MAX.saturating_add(Q16::ONE);
    assert!(s.saturated && s.value == Q16::MAX);

    // 4. Интервалы с округлением наружу: точный результат остаётся внутри.
    let around_one = Interval::new(Q16::from_raw(65535), Q16::from_raw(65537)).unwrap();
    let p = around_one.mul(Interval::point(x)).unwrap(); // 3.0 * (1 ± 1 ulp)
    assert!(p.contains(x));
    println!("3.0 * [1 ∓ 1 ulp] = [{}, {}]", p.lo, p.hi);
    // -> [2.9999542236328125, 3.0000457763671875]
}
```

## Что внутри

- `Op::{MulOdd, Add, Xor, RotL}` — биективные примитивы с
  `.apply()` / `.inverse()`; `mod_inv_odd(a)` — модулярная инверсия по
  модулю 2^64; `Compose` — билдер с точной аналитической инверсией;
  `arx_round` / `arx_round_inv` — обратимый ARX-раунд на паре слов;
- `Fixed<FRAC>` — обобщённая фиксированная точка (значение = `raw / 2^FRAC`,
  raw — `i64`); `Q16` — классический Q16.16. Проверяемые операции возвращают
  `Option` (вне домена — `None`, вызывающий откатывает фазу: fail = un-run);
  насыщающие возвращают значение плюс флаг `saturated`;
  `sqrt`, `pow2`, `log2`, точный десятичный `Display`;
- `Interval<FRAC>` — замкнутые интервалы с округлением наружу: точный
  вещественный результат гарантированно внутри, иначе операция возвращает
  `None`;
- легаси-функции `q_*` над `Q = i64` (Q16.16), сохранены для совместимости.

## Бюджеты погрешности и классификация

Каждая операция классифицирована и оценена в
[docs/math-spec.md](docs/math-spec.md): операция → домен → обратная операция
→ класс (биекция / частично обратимая / с потерей) → граница погрешности или
гарантия вложенности. Примеры:

| Операция | Класс | Худшая погрешность |
|---|---|---|
| `MulOdd`, `Add`, `Xor`, `RotL`, `Compose`, `arx_round` | биекция | точно (0) |
| `Fixed::checked_mul` | с потерей (floor) | `−2^−FRAC < err ≤ 0` (≤ 1 ulp) |
| `Fixed::checked_div` | с потерей (floor) | `−2^−FRAC < err ≤ 0` (≤ 1 ulp) |
| `Fixed::sqrt` | с потерей (floor) | `−2^−(FRAC/2) < err ≤ 0` (≤ 256 ulp для Q16) |
| `Interval::mul` / `div` | наружное округление концов | концы в пределах 1 ulp от точных экстремумов; ширина ≤ точная + 2 ulp |
| насыщающие операции | с потерей при клампинге | флаг `true` = числовой границы нет, значение — кламп |

## Честность и рамки

- Арифметика, дружественная к обратимости, для VM: биективное семейство
  обратимо точно; фиксированная точка и интервалы проверяют домен и несут
  бюджеты погрешности, чтобы VM знала, что должен отменять rollback.
- Границы погрешности — **верхние оценки худшего случая**, выведенные
  аналитически и закреплённые детерминированными рандомизированными тестами
  против точных i128-ссылок (float нет нигде, включая тесты). Это гарантии,
  проверенные тестами, а не формальные доказательства.
- Обещаний больше реализованного нет: нет float, нет трансцендент кроме
  `2^x` и `floor(log2)`, нет NaN и бесконечностей; интервалы возвращают
  `None` вместо расширения; насыщающие результаты несут флаг вместо
  границы; легаси-API `q_*` задокументировано ровно так, как оно себя ведёт
  (включая консервативную проверку переполнения), и заморожено.
- API может меняться до версии 1.0. Спецификация в
  [docs/math-spec.md](docs/math-spec.md) версионируется вместе с крейтом.

## Тесты

Всего 56 тестов (`cargo test`): обратимости биекций на граничных значениях и
больших случайных выборках; тесты границ погрешности против точных i128-ссылок
(200 тыс. случайных полнодиапазонных выборок для границ mul/div); проверки
бюджета насыщения; вложенность интервалов и точность концов при наружном
округлении; предусловия частичных обратимостей и конкретные примеры потери
информации; док-тесты документированных примеров. Полная карта
«утверждение → тест» — в [docs/math-spec.md](docs/math-spec.md).

Часть архитектуры PHASE (github.com/kostyk348/phase-arch) — слой обратимой
математики; референсная реализация живёт вместе с phase-vm.
